 # Poiesis 2025 - Cultural Fest Website

## Quick Deploy Command
```bash
git add . && git commit -m "Update website" && git push origin main
```

## Manual gh-pages Deploy (if needed)
```bash
git push origin main:gh-pages --force
```

An Inter-School/Collegiate Cultural Fest by Sacred Heart Girls' High School featuring Dance, Music, Art, Fashion and more events scheduled for August 1st & 2nd, 2025.
